## Known items

- `npm audit` reports 11 moderate findings, all one advisory in `minimatch`
  (GHSA-g3hv-75wg-m249) reached only through eslint, a development tool not
  shipped to users. The suggested `npm audit fix --force` would downgrade eslint
  to 4.0.0, so it was not applied. Re-check when eslint updates its dependency.
- Legacy prints one `SyntaxWarning` from the third-party `sgfmill` package
  (an invalid escape sequence in its source) when compiled on Python 3.14; it
  does not affect results.
- The legacy macOS launchd start (`legacy/Start Go Review.command`) was not
  exercised; the same app was run directly with uvicorn instead.
- The legacy `Dockerfile` labels the image `licenses="MIT"`; the project licence
  is now Apache-2.0. Legacy is frozen, so the label is left as history.
- rustup from Homebrew is keg-only: shells need
  `/opt/homebrew/opt/rustup/bin` on `PATH` (owner's shell profile).
